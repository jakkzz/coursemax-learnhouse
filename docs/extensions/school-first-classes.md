# School-first My classes

## Direction contract

**THESIS — Operate.** Show the signed-in teacher's official NRRU sections first;
opening an official class must not require a LearnHouse course or connection.
Reject the previous integration-status-first workspace.

**OWN-WORLD.** Preserve native LearnHouse navigation, typography, white surfaces,
blue actions/selection and existing weekday colors. Use compact aligned class rows,
not a repeated wall of setup cards. Ordinary unmatched classes are neutral.

**STORY.** Choose a term, find a class, inspect its official details, weekly meetings
or official students. LearnHouse classes remain a separate source with explicit
connections. Only the existing verified own-school association authorizes retrieval;
an email domain is not an ownership assertion.

**FIRST VIEWPORT.** My classes heading, NRRU/LearnHouse source navigation, term and
search controls, then official course/section rows with meeting summaries and a
clear Open class action. Details use one title and three task views. The signature
interaction keeps official facts usable before connecting a learning workspace.

**FORM.** User-pinned school-first index → details/schedule/roster, independent
LearnHouse list; confirmation narrowed “all classes” to the user's NRRU account.
Code-led extension of the incumbent visual system, not a global replacement world.
No new assets, synthetic production content or inferred dated attendance sessions.

**FINISH.** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Root DESIGN.md is outside the owned write boundary and has known historical drift;
preserve it. Record scoped evidence here after the bounded desktop/mobile review.
Official roster reads do not import, accept missing snapshots, match accounts or
change LearnHouse membership, grants, enrollment or progress. Existing connection
and saved-roster editing workflows remain explicit and separate.

use subtle alternating white/slate rows. Source controls and refresh targets are
